Install inone line.

The Windows installer puts consil.exe in your user folder and adds it to PATH. The macOS and Linux installer puts consil in ~/.local/bin. Read either script first: install.ps1, install.sh.

# Windows PowerShell
irm /install.ps1 | iex

# macOS / Linux
curl -fsSL /install.sh | sh

# verify a download (PowerShell)
Get-FileHash .\consil-win-x64.exe -Algorithm SHA256

Windows may warn that the app is from an unknown publisher: the build is not code-signed yet. Compare the SHA-256 above before you run it.
