Quick start

CONSILIUM runs in three places with the same four agents: the web desk, the Windows app and the terminal CLI. Nothing needs an account or a wallet.

Windows (no Node needed)

irm /install.ps1 | iex
consil council NVDA

macOS and Linux (Node.js 20+)

curl -fsSL /install.sh | sh
consil council NVDA

Any OS with npm

npm i -g /dl/consil-cli.tgz

Prefer to download by hand? Every file is on the download page with its SHA-256.

Terminal commands

CommandWhat it does
consilInteractive desk. Type a question, or /council NVDA, /markets, /watch NVDA, /ledger, /status, /exit. Follow-up questions can refer to the council you just ran.
consil ask "..."Streams an answer from the desk. Name a ticker and the desk convenes the council on it first. Answers are in English.
consil ask --agent risk "..."Ask one agent instead of the chair: scout, quant, risk or exec. Each answers from its own role and numbers.
consil markets [crypto|stocks]Live markets on Lighter (Robinhood Chain): stock tokens on spot in USDG, and crypto (BTC, ETH, SOL, HYPE and more) on spot or perpetual markets, with 24h change and volume.
consil council NVDAThe four agents vote on one market and the verdict is printed with each agent's case.
consil watch NVDA --every 60Runs the council on a timer (30 s minimum) and paper-trades every BUY or SELL verdict.
consil ledger [--reset]Positions, the last fills and equity, marked at the live price.
consil key sk-ant-...Use your own Claude key for answers and agent cases. consil key --clear removes it.
consil statusChecks market data, the desk API and which answer source is active.

Options: --api <url> or CONSIL_API points at another desk server, NO_COLOR=1 prints plain text, CONSIL_HOME moves the data folder.

How a vote works

All four votes are plain code. Claude only writes each agent's one-line case from the numbers and cannot change a vote or the verdict.

AgentReadsVotes
SCOUTEMA20 against EMA50 on 1h candles, and the 24h changeBUY when EMA20 is more than 0.15% above EMA50 and the day is not down more than 1%. SELL in the mirror case. Otherwise HOLD.
QUANTRSI14 on 1h candlesBUY under 35, SELL over 65, otherwise HOLD.
RISKMarket status, spread, 24h volume, hourly volatilityAPPROVE only if the market is open, the spread is at most 40 bps, 24h volume is at least $5,000 and hourly volatility over the last day is at most 3.5%. Otherwise VETO.
EXECThe live order bookWalks the book for a 250 USDG ticket in the trade's direction. READY if it fills with at most 50 bps slippage, otherwise BLOCK.

The direction comes from SCOUT and QUANT. If they point opposite ways there is no trade. A RISK veto or an EXEC block always stops the trade. Otherwise at least 3 of the 4 agents must be behind it.

Change the rules

Every number above is a rule you can change on the web desk (Rules tab, or the Cautious, Balanced and Aggressive presets) or through the API. The server clamps each value to its range:

Paper ledger

Every account starts with 1,000 USDG of paper cash. A BUY verdict opens a 250 USDG position at EXEC's average fill price if you hold none; a SELL verdict closes it. No order is ever sent.

The terminal app stores the ledger in ~/.consilium/ledger.json. The web desk stores it in your browser.

API reference

Public, read-only, JSON. Rate limits: 240 requests a minute per IP, 20 questions per 10 minutes.

GET /v1/markets?asset=crypto

asset is optional: stock or crypto. Crypto uses whichever Lighter market trades more for that coin, spot or perpetual; paper trades on perps are long or flat, no leverage.

{ "ok": true, "markets": [ { "symbol": "BTC", "pair": "BTC-PERP", "asset": "crypto", "kind": "perp", "last": 61325.4, "change24hPct": 1.01, "dayVolumeUsd": 144946450, "tier": "liquid" } ] }

GET /v1/council/:symbol

{ "ok": true, "council": {
  "symbol": "NVDA", "price": 136.14, "quorum": 3,
  "votes": { "scout": { "vote": "BUY", "facts": { "ema20": 134.37, "ema50": 134.01 } }, "quant": { ... }, "risk": { ... }, "exec": { ... } },
  "verdict": { "action": "BUY", "behind": 3, "reason": "3 of 4 agents agree." },
  "brief": { "scout": "...", "quant": "...", "risk": "...", "exec": "...", "chair": "..." } } }

Add any rule as a query parameter to vote with your own rules, for example /v1/council/NVDA?quorum=4&maxSpreadBps=20. Add brief=0 to skip the agents' written case (faster, used by the live watchlist).

GET /v1/rules

The default rules and the [default, min, max] range of each.

GET /v1/candles/:symbol?res=1h&count=300

Candles from Lighter. res is one of 1m, 5m, 15m, 1h, 4h, 1d; count 10 to 500. The web desk polls this every 5 seconds to keep its chart live.

POST /v1/ask

Body {"question": "...", "agent": "risk", "rules": {"quorum": 4}, "history": [{"role":"user","content":"..."},{"role":"assistant","content":"..."}]}; agent (chair, scout, quant, risk, exec) and rules are optional, question up to 600 characters. The answer streams as server-sent events: context, then text chunks, then done or error.

curl -N /v1/ask -H "content-type: application/json" \
  -d '{"question":"Why would RISK veto AMD?"}'

GET /v1/health

Version, mode (always paper) and whether the model is online.

Your own Claude key

By default the app asks our desk API. With consil key sk-ant-... the app talks to Claude directly with your key, so questions never pass through our server. The key is saved in ~/.consilium/config.json, readable only by your user.

Run your own desk

git clone <your copy> consilium && cd consilium
npm install
ANTHROPIC_API_KEY=sk-ant-... npm start      # http://127.0.0.1:5120
node cli/build.mjs --api https://your-desk.example   # rebuild the downloads

Set SITE_URL so the install scripts point at your domain, and TRUST_PROXY=1 behind a reverse proxy.

Data and privacy

Market data is Lighter's public, read-only API for Robinhood Chain. The desk keeps no accounts and no wallets. Questions sent to the desk API are passed to Claude to write the answer and are not stored by the desk. Paper mode only: this is not financial advice and CONSILIUM is not affiliated with Robinhood.
